# 交通规划过程

## 概述

交通规划决定如何分配稀缺资源（土地、道路空间、资金和时间）来运送人和货物。由于基础设施的建设需要数年，使用寿命长达数十年，决策必须基于对出行者如何响应未来的土地利用格局和未来交通系统的预测。本章说明为什么需要这样的预测、规划过程如何组织、交通需求与供给有何特殊之处，以及经典的**四阶段法**（four-step model）如何把土地利用数据转化为网络流量的预测。本书其余各章分别展开该模型的各个部分。

:::{admonition} 学习目标
:class: objectives
学完本章后，读者应能够：

- 解释为什么需要城市交通规划，并对比理性规划过程与政治规划过程；
- 列出主要的规划分析类型及其时间范围；
- 描述交通需求和交通供给的特点；
- 阐述需求–性能均衡框架，并说明规划试图借助它预测和控制什么；
- 描述经典交通模型的四个阶段以及反馈的作用；以及
- 讨论主要的建模选择：集计与非集计、截面与时间序列、显示性偏好与陈述性偏好。
:::

## 为什么要进行交通规划？

新加坡这样的高密度城市可以说明问题所在。有限的土地面积必须容纳大量人口、大量就业岗位以及二者之间的出行。高峰时段道路网络上的需求经常超过其通行能力，于是出行时间增加，公交车延误，排放、噪声和事故增多。拥堵的代价既由个人承担（出行时间、车辆运行成本），也由社会承担（污染、安全、生产力损失）。

缓解拥堵有四大类策略：

1. **增加通行能力**——新建道路、增加车道、新建轨道线路。在拥堵的道路网络上新增的通行能力往往会被新增的或改道而来的出行所填满（*诱增需求*，induced demand），因此仅靠这一策略很少能消除拥堵。
2. **更好地利用现有通行能力**——信号控制、匝道控制、事件管理以及其他智能交通系统（ITS）。
3. **管理需求**——拥堵收费、停车收费、车辆配额，以及鼓励错峰出行的激励措施。
4. **改善公共交通**——更频繁、更可靠的公交和轨道服务、一体化票制，以及更好的步行和自行车接驳。

上述每一种策略都会改变出行条件，出行者会通过改变路径、方式、目的地、出发时间，乃至居住和工作地点作出反应。规划就是预测这些反应，并选择最能实现社会目标的措施组合。从这个意义上说，规划是一个受通行能力和预算约束的**资源分配（最优化）问题**：它分配道路空间和线路、时间（信号相位、时刻表）、资金和土地。

## 理性规划与政治规划

对于规划决策如何形成，有两种程式化的描述很有用。

**理性规划过程**（rational planning process）按固定顺序进行：

1. *确定目标*——识别社会价值，陈述总目标和具体目标，并为每个目标选择效果度量指标。
2. *识别需求*——将交通系统的实际表现与目标进行比较；存在差距即为需求。
3. *拟定备选方案*——提出针对每项需求的措施。
4. *评价备选方案*——通常借助交通模型，预测每个方案在物理、经济、环境和社会方面的影响。
5. *实施*——选择首选方案，筹措资金并建设，然后监测其效果。

**政治规划过程**（political planning process）则从一个具体提案出发（例如“修建一条通往机场的轨道线路”）。提案的支持者通过协商、游说和公众舆论争取支持；提案经过修改并反复提出，直到形成决定性的行动，例如资金决策、选举结果或立法。

实际决策兼有二者。本书的模型直接服务于理性过程：它们量化需求并预测每个方案的后果，这也为政治辩论提供了约束。

## 规划分析的类型

规划涉及不同的交通方式、地理尺度、时间范围和利益相关方：

| 类型 | 典型问题 | 时间范围 |
|---|---|---|
| 长期（战略）规划 | 新建快速路或轨道线路；土地利用–交通战略 | 10–30 年 |
| 政策分析 | 拥堵收费、停车收费、票价、合乘（HOV）车道、增长情景 | 5–20 年 |
| 项目规划与影响评价 | 开发项目或新建路段的交通影响 | 1–10 年 |
| 公共交通规划 | 线路、发车频率、票价；需要方式选择模型 | 1–10 年 |
| 非机动（主动出行）规划 | 自行车和步行网络、首末公里接驳 | 1–10 年 |
| 货运规划 | 货车出行、物流枢纽、服务车辆 | 5–20 年 |
| 土地利用规划 | 住宅和就业的区位，及其与可达性的相互作用 | 10–30 年 |

绩效指标针对基年和每个目标年设定。常用的系统层面指标有车辆行驶公里数（VKT）、车辆行驶小时数（VHT）、平均车速以及路段的流量–通行能力比（饱和度）。

城市特征影响所有这些分析：人口规模与人口结构（包括老龄化）、收入，以及建成环境的“D”变量——**密度**（density）、**多样性**（diversity，土地利用混合程度）和**设计**（design，街道布局、步行设施）（Cervero & Kockelman, 1997），后来的研究又加入了**目的地可达性**（destination accessibility）和到公共交通站点的距离（Ewing & Cervero, 2010）。

## 需求与供给的特点

### 交通需求

- **需求是派生的。** 人们出行是为了在其他地点参加活动（工作、上学、购物、休闲）；货物运输是为了在别处使用。出行本身很少是目的。
- **需求是有差异的。** 它随一天中的时段、一周中的日子、出行目的而变化，也随出行者对速度、频率、可靠性和舒适性的重视程度而变化。
- **需求发生在空间中。** 活动的空间分布产生具有特定起点和终点的出行，这正是需要把研究区域划分为交通小区的原因。
- **需求有高峰。** 大量出行集中在早晚两个短暂的高峰时段，而基础设施必须按高峰需求设计。

### 交通供给

- **供给是服务而不是商品。** 一个座位公里或一个道路时隙如果在其产生的时间和地点没有被使用，就会损失掉；它不能储存。
- **供给由固定设施、移动设备和规则共同构成。** 基础设施（道路、轨道）、车辆以及运营规则和法规共同产生服务。
- **基础设施具有不可分性。** 一条道路或轨道线路不能只建一半；它以大型、不可分割的单元提供，需要数年才能完成。
- **供给会拥堵。** 当流量接近通行能力时，每个使用者的出行时间都会增加。每增加一名出行者，都会给其他所有人带来额外延误，这是个体出行者不会考虑的*外部成本*（这一思想在{doc}`14-system-optimum-and-elastic-demand`中还会出现）。
- **各方式相互作用。** 有些方式相互补充（接驳轨道的公交、停车换乘），另一些则相互竞争（机场巴士与轨道）。

## 需求–性能均衡

需求与供给的相互作用可以用几个汇总量来概括：

| 符号 | 含义 |
|---|---|
| $E$ | 活动系统（activity system）：人口、就业和其他活动的空间分布 |
| $Q$ | 交通系统的通行能力 |
| $M$ | 交通控制与管理系统 |
| $I$ | 投资计划 |
| $F$ | 交通流量（显示的需求） |
| $L$ | 服务水平（level of service；出行时间、费用、可靠性） |

**性能（供给）函数**（performance function）给出系统承载流量 $F$ 时所提供的服务水平：

$$
L = P(Q, F, M; \balpha),
$$ (eq-05-performance-function)

其中 $\balpha$ 为其参数。通行能力本身取决于管理和投资，$Q = Q(M, I)$。**需求函数**（demand function）给出活动系统在给定服务水平下产生的流量：

$$
F = D(E, L; \bbeta),
$$ (eq-05-demand-function)

参数为 $\bbeta$。服务水平改善时需求增加，而流量增加时服务水平下降（拥堵）。**需求–性能均衡**（demand–performance equilibrium）$(F^*, L^*)$ 同时满足 {eq}`eq-05-performance-function` 和 {eq}`eq-05-demand-function`：

$$
(F^*, L^*) = Z(E, M, I; \balpha, \bbeta).
$$ (eq-05-equilibrium)

```{figure} figures/05-demand-supply-equilibrium.svg
:name: fig-05-demand-supply-equilibrium
:width: 520px
:class: dark-light

以出行费用（服务水平的倒数）表示的需求–性能均衡。活动系统从 $E_1$ 增长到 $E_2$ 使需求曲线移动，均衡点移向更高的流量和更高的费用。
```

{numref}`fig-05-demand-supply-equilibrium`给出了这两条曲线。在这一框架下，交通规划有两个目标：

1. **预测**——预测当活动系统 $E$、管理 $M$ 和投资 $I$ 随空间和时间变化时 $(F^*, L^*)$ 如何变化。
2. **设计**——选择 $M$ 和 $I$（并通过土地利用政策影响 $E$），使均衡朝期望的方向移动，例如使社会福利最大或系统总出行时间最小。

由于活动系统本身也会对服务水平作出反应（可达性变化时企业和家庭会迁移），存在两种均衡：$E$ 固定时的**短期**均衡，以及土地利用也随之调整的**长期**均衡。本书的四阶段法计算的是短期均衡；长期均衡由土地利用–交通相互作用模型处理。

:::{admonition} 小汽车–公共交通的恶性循环
:class: tip
收入增长使小汽车拥有量增加，需求从公共交通转向小汽车。公共交通客流和收入减少，服务被削减，服务水平下降，使小汽车更具吸引力。与此同时，道路拥堵延误公交车，使其服务水平进一步恶化。打破这一循环需要同时作用于多个环节的政策：道路收费或停车政策、公交优先，以及对公共交通的投资。
:::

## 经典四阶段法

**经典交通模型**（classical transport model），也称四阶段法，是战略交通规划的骨干（{numref}`fig-05-four-step-model`）。它以交通小区系统和编码后的网络（{doc}`06-zoning-and-networks`），以及基年和规划年的人口、就业和土地利用数据为起点。

```{figure} figures/05-four-step-model.svg
:name: fig-05-four-step-model
:width: 560px
:class: dark-light

四阶段法。第 1–3 步建模出行需求；第 4 步把需求加载到网络上。第 4 步得到的拥堵出行时间反馈给前面各步，直到需求与出行时间相互一致。
```

1. **出行生成**（trip generation）估计每个小区的出行产生量和吸引量 $O_i$ 和 $D_j$（{doc}`09-trip-generation`）。
2. **出行分布**（trip distribution）将每个小区的出行产生量分配到各目的地，得到出行矩阵 $\{T_{ij}\}$（{doc}`10-trip-distribution`）。
3. **交通方式划分**（modal split）将矩阵的每个单元分配到可用的各交通方式，得到 $T_{ij}^m$（{doc}`11-discrete-choice-models`、{doc}`12-aggregate-modal-split`）。
4. **交通分配**（traffic assignment）按某种路径选择原则把各方式的矩阵加载到相应网络上，得到路段流量 $x_a$ 和行程时间 $t_a(x_a)$（{doc}`13-user-equilibrium-assignment`、{doc}`14-system-optimum-and-elastic-demand`、{doc}`15-stochastic-user-equilibrium`）。

各步骤的顺序只是建模上的便利，并不表示人们就是这样决策的。出行时间进入第 2 步和第 3 步，但只有在第 4 步之后才能知道，因此一个自洽的模型需要迭代：把第 4 步得到的拥堵时间反馈给出行分布和方式选择，直到每一步的输入与输出相互一致。{doc}`14-system-optimum-and-elastic-demand`表明，某些步骤的组合可以作为单个凸优化问题同时求解。

基于活动的模型用每日活动日程以及连接这些活动的出行链代替单次出行；MATSim 等基于智能体的仿真器则对每个出行者分别建模（{doc}`16-dynamic-assignment-and-simulation`）。

### 连续规划过程

20 年期的规划只有到期时才能得到检验。因此，好的做法是把规划视为一个**连续过程**：由监测系统收集交通系统及关键外生变量（人口、经济增长）的数据，发现与预测的偏离，并触发模型和规划的更新。

## 建模选择

在确定建模方法时，分析人员需要权衡所需的精度、决策背景、细节程度（空间、人群细分、时间）、可用的数据和资源，以及团队的技能。有几种反复出现的选择值得一提。

集计模型与非集计模型
: 集计模型描述出行者群体（小区、家庭类别）；非集计模型描述单个决策者，之后再进行集计。非集计模型对数据的利用效率更高，行为基础也更强，但用于预测时需要一个集计步骤。

截面数据与时间序列数据
: 大多数规划模型用某一时点的个体截面数据估计，并假设所得关系在未来仍然成立。时间序列数据和面板数据能揭示行为的实际变化，但采集成本高。

显示性偏好与陈述性偏好
: 显示性偏好（RP）数据记录实际选择；陈述性偏好（SP）数据记录对假设情境的回答。SP 数据可以研究尚不存在的选项（新的交通方式、新的收费），但必须校正陈述行为与实际行为之间的差距（{doc}`07-travel-surveys-and-sampling`）。

演绎方法与归纳方法
: 模型可以从行为理论（效用最大化、均衡）演绎得到，也可以从数据中的规律归纳得到。基于理论的模型通常更容易移植到新的条件。

## 本章回顾

### 小结

- 规划分配稀缺的通行能力、时间和资金；它需要预测出行者对交通系统变化的反应。
- 交通需求是派生的、有差异的、空间的、有高峰的；交通供给是不可储存、不可分、会拥堵的服务。
- 流量和服务水平由性能函数 {eq}`eq-05-performance-function` 和需求函数 {eq}`eq-05-demand-function` 共同决定；二者的解就是需求–性能均衡 {eq}`eq-05-equilibrium`（{numref}`fig-05-demand-supply-equilibrium`），规划通过管理和投资预测并引导这一均衡。
- 四阶段法分四个阶段——生成、分布、方式划分和分配——计算短期均衡，各阶段通过拥堵出行时间的反馈相连（{numref}`fig-05-four-step-model`）。

### 常见错误

- **把四个阶段当作对个体决策过程的描述。** 它们是对一个均衡问题的计算分解；出行者并不是先决定是否出行、再决定去哪里、再决定用什么方式、最后决定走哪条路径。
- **只运行一遍四个阶段而不反馈。** 这样出行分布和方式选择使用的出行时间与交通分配得到的拥堵时间不同，预测相互矛盾；应迭代直到出行时间一致。
- **认为新增的道路通行能力会使拥堵按同等幅度减少。** 需求会对改善后的服务水平作出反应（诱增需求），因此新的均衡流量更高，节省的时间比按固定需求计算的要少。
